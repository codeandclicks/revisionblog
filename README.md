# Revision Blog

A simple static blog built with [Hexo](https://hexo.io/) and the Landscape theme. Blog posts are written in Markdown and stored in `source/_posts/`.

## Run locally

Requires Node.js and npm.

```bash
npm install
npm run server
```

Open the local URL printed by Hexo (usually http://localhost:4000).

## Build

```bash
npm run build
```

Generated static files are placed in `public/`. Site settings, including the title and author, can be changed in `_config.yml`.
